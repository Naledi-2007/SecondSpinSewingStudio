# Second Spin Sewing Studio

## Project Overview
Second Spin Sewing Studio is a website developed to showcase sewing services, clothing repairs and sustainable fashion. The website provides visitors with information about the studio, its services and ways to make enquiries.

## Website Pages

The website consists of the following pages:

- **Home:** Introduces Second Spin Sewing Studio.
- **About:** Provides information about the studio.
- **Services:** Displays the services offered by the studio.
- **Gallery:** Showcases sewing, clothing repairs and upcycling images with interactive category filters and an image enlargement feature.
- **Enquiry:** Allows visitors to submit an enquiry form.
- **Contact:** Provides contact information and a contact form.
- **Mandela Day:** Highlights the studio's Mandela Day activities.

## Technologies Used

- HTML5 – Website structure and content.
- CSS3 – Styling, layout and responsive design.
- JavaScript – Interactive features and form validation.
- Visual Studio Code – Development environment.
- GitHub – Version control and project hosting.
- GitHub Pages – Website deployment.

## JavaScript Features

The website includes the following JavaScript functionality:

- Service search functionality to help visitors find specific services.
- Enquiry form validation.
- Contact form validation and email preparation.
- Interactive gallery with category filtering for repairs, upcycling and sewing.
- Image lightbox functionality that allows visitors to enlarge gallery images.

## Search Engine Optimisation (SEO)

SEO improvements implemented include:

- Page titles and meta descriptions.
- Alternative text (alt attributes) for images.
- Internal navigation links between website pages.
- A `robots.txt` file.
- An XML sitemap listing all seven website pages.

## Responsive Design

The website uses responsive design techniques to improve its display across different screen sizes, including desktop and mobile devices.

## Testing
