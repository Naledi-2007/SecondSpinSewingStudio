# Second Spin Sewing Studio

## Website Project

Second Spin Sewing Studio is a community-focused website that promotes clothing repair, alterations, upcycling, sewing workshops and sustainable fashion.

The website also promotes the studio's Mandela Day initiative, where community members are encouraged to spend 67 minutes volunteering and giving back.

## Responsive Design

The website was designed to work on different screen sizes.

Two main CSS breakpoints were added:

### Tablet - 768px

At screen sizes of 768px and below:

- Two-column sections change to single-column layouts where needed.
- Content is easier to read on smaller screens.
- Images resize according to the available space.
- Cards adjust to fit the screen.

### Mobile - 480px

At screen sizes of 480px and below:

- Navigation links are displayed vertically.
- Content changes to a single-column layout.
- Buttons become easier to use on smaller screens.
- Images resize automatically.
- Forms adjust to the width of the screen.
- Font sizes and spacing are adjusted for mobile devices.

---

## Responsive Images

Responsive image techniques were added to improve how images appear on different devices.

The website makes use of:

- `<picture>`
- `srcset`
- `sizes`
- CSS `max-width: 100%`
- Automatic image height

These techniques allow images to adjust according to the user's screen size.
