
# Second Spin Sewing Studio

## Project Overview
Second Spin Sewing Studio is a website promoting sustainable fashion, clothing repairs, alterations, and upcycling. It provides visitors with information about the studio, its services, and ways to make enquiries.

## Website Pages
- Home: Introduces the studio and its purpose.
- About Us: Explains the studio's background and mission.
- Services: Displays available services and includes a search feature.
- Enquiry: Allows visitors to submit an enquiry form.
- Contact: Provides contact information and a contact form.
- Mandela Day: Highlights the studio's community involvement.

## Technologies Used
- HTML5 for website structure.
- CSS3 for styling and responsive design.
- JavaScript for search functionality and form validation.
- GitHub for version control and project hosting.

## JavaScript Features
- Search and filter services.
- Validate enquiry form fields.
- Validate contact form fields.
- Prepare contact messages using the visitor's default email application.

## SEO Improvements
- Page-specific titles and meta descriptions.
- Semantic headings and descriptive image alternative text.
- Internal navigation links.
- robots.txt and sitemap.xml files.

## How to Run the Website
Open `index.html` in a web browser.
